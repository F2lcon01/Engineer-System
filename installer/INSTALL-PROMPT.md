# برومبت تثبيت Engineer System عبر Claude

استخدم هذا البرومبت داخل أي جلسة Claude Code (في أي مشروع) لتثبيت النظام بدون تشغيل سكريبتات يدوية. Claude سيقرأ الملفات من المسار، يفحص الـ conflicts، وينقل كل شيء بذكاء.

---

## البرومبت (انسخه كما هو والصقه في Claude Code)

```
ثبّت Principal Engineer System في هذا المشروع. اتبع هذا البروتوكول بدقة:

## المصدر
نسخة النظام محفوظة في: ~/Desktop/Engineer System (إذا لم تجده هناك، اسألني عن المسار)

## الخطوات الإلزامية

### 1. فحص المسار الحالي
- استخرج اسم المشروع الحالي (basename للـ pwd)
- تحقق هل المشروع git repo (وجود .git/)
- تحقق هل CLAUDE.md، .claude/، أو memory/PROJECT_MAP.md موجود

### 2. تحليل الـ Conflicts
- إذا CLAUDE.md موجود → اقرأه واحفظ التخصيصات في القسم "ملاحظات السياق" 
- إذا memory/PROJECT_MAP.md موجود وفيه أكثر من القالب → احفظه كاملاً، لا تكتب فوقه
- إذا .claude/ موجود → عدّ ملفاته وأخبرني قبل الاستبدال

### 3. عرض خطة التثبيت قبل التنفيذ
أعرض جدول واضح:
| الملف | الحالة | الإجراء المقترح |
|-------|--------|----------------|
| CLAUDE.md | جديد/موجود | إنشاء/تحديث/دمج |
| .claude/agents/*.md | جديد/موجود | إنشاء/استبدال |
| .claude/commands/*.md | جديد/موجود | إنشاء/استبدال |
| .claude/hooks/*.sh | جديد/موجود | إنشاء/استبدال + chmod +x |
| .claude/settings.json | جديد/موجود | إنشاء/استبدال |
| memory/PROJECT_MAP.md | جديد/له بيانات | إنشاء/حماية |

ثم اسألني: "هل أتابع التثبيت؟" — انتظر تأكيدي.

### 4. التنفيذ بعد التأكيد
- انسخ الملفات حسب الخطة
- شغّل: chmod +x .claude/hooks/*.sh
- إذا الـ project git repo:
  - تحقق من .gitignore
  - أضف السطرين التاليين إذا غير موجودين:
    # Principal Engineer System
    .claude/.session-edits.log

### 5. تخصيص CLAUDE.md لهذا المشروع
بعد النسخ، اعرض القسم الحالي "ملاحظات السياق" من CLAUDE.md واسألني:
- ما اسم المشروع ووصفه المختصر؟
- ما التقنيات الرئيسية المستخدمة؟
- ما هيكل المجلدات؟
- ما المعايير الخاصة بهذا المشروع؟

بناءً على إجاباتي، حدّث القسم بدقة.

### 6. التحقق النهائي
- تأكد أن كل الملفات منسوخة (اعرضها بـ tree أو find)
- تأكد أن hooks لديها صلاحيات تنفيذ
- اقترح خطوة تالية: "أعد فتح Claude Code أو اكتب /agents للتحقق"

## القيود
- لا تحذف أي ملف موجود قبل سؤالي
- لا تكتب فوق PROJECT_MAP.md إذا فيه بيانات
- لا تفترض اسم المشروع — استخرجه من pwd
- إذا حدث خطأ، أوقف العملية واعرض الحالة الحالية
```

## بدائل أبسط

إذا لا تريد البرومبت الطويل، استخدم هذه النسخة المختصرة:

```
ثبّت Engineer System من ~/Desktop/Engineer System في هذا المشروع.
احفظ بياناتي الموجودة (CLAUDE.md، PROJECT_MAP.md إذا موجودة).
اعرض الخطة قبل التنفيذ، انتظر موافقتي، ثم نفّذ.
في النهاية: chmod +x للـ hooks، وحدّث .gitignore إذا git repo.
```

## مزايا الطريقة (Claude vs PowerShell)

| الميزة | PowerShell Script | Claude Prompt |
|--------|------------------|---------------|
| سرعة التنفيذ | فوري | يستغرق دقيقة (Claude يفكر) |
| التخصيص الذكي | محدود | يسأل عن مشروعك ويعدّل |
| اكتشاف Edge Cases | حسب الكود | Claude يكتشف ما لم تخطط له |
| التفاعل | غير تفاعلي | يتحاور معك |
| الموثوقية | عالية ومضمونة | تعتمد على فهم Claude |

**التوصية:**
- للتثبيت الأولي: PowerShell (مضمون 100%)
- للترقية مع تخصيص: Claude Prompt (يستفسر ويتكيف)
